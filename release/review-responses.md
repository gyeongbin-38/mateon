# 스토어 리뷰 답변 템플릿

공통 원칙: 48시간 이내 답변, 감정에 호응 → 원인 파악 → 다음 행동 안내. 개인정보는 절대 묻지 않는다 (로컬-퍼스트라 수집 불가).

## 동기화가 안 돼요

> 불편을 드려 죄송해요. 동기화는 설정 → 동기화에서 같은 방 코드를 두 기기에 입력해야 해요. 방 코드가 같은데도 안 되면 ① 두 기기 모두 최신 버전인지 ② 동기화 서버 URL이 같은지 확인해 주세요. 계속 안 되면 지원 이메일로 방 코드 없이 증상만 알려 주시면 도와드릴게요.

## 데이터가 사라졌어요

> 많이 당황하셨겠어요. MATE:ON 데이터는 기기에만 저장돼서, 브라우저 데이터 삭제나 기기 변경 시 사라질 수 있어요. 설정 → 백업에서 미리 만들어둔 백업 파일이 있다면 복원할 수 있습니다. 앞으로는 설정 → 백업에서 파일을 정기적으로 저장해 두시길 권해드려요. 복원이 안 되면 지원 이메일로 상황을 알려 주세요.

## 앱이 느려요 / 멈춰요

> 불편을 드려 죄송해요. 어떤 화면에서 멈추는지(정산/캘린더/검색 등) 리뷰에 적어 주시면 바로 확인하겠습니다. 영수증 스캔은 기기에서 직접 인식이라 처음엔 시간이 걸릴 수 있어요 — 두 번째부터는 빨라집니다.

## 진단 결과가 이상해요

> 솔직한 의견 감사해요. 20문항 진단은 생활 경향의 참고 지표일 뿐 두 분의 관계를 점수 매기지는 않아요. 문항을 다르게 해석해 다시 해보시거나, 설정에서 실무 성향 체크까지 해보시면 더 구체적인 비교가 나옵니다. 특정 문항이 어색했다면 어느 문항인지 알려 주세요.

## 원하는 기능이 없어요

> 좋은 아이디어 감사해요! 지금은 지출·집안일·일정·체크인 중심인데, 어떤 기능이 있으면 두 분 생활에 도움이 될지 알려 주시면 다음 업데이트에 참고하겠습니다.

## iOS/Android 특정 OS 문제

> 해당 OS에서 발생한 문제를 확인 중이에요. 기기 모델과 OS 버전을 리뷰에 남겨 주시면 재현해서 고치겠습니다. 급하시면 지원 이메일로 스크린샷을 보내 주세요.

## 별점만 낮고 내용이 없을 때

> 소중한 시간 내 별점을 남겨 주셔서 감사해요. 어떤 점이 아쉬웠는지 한 줄이라도 알려 주시면, 다음 업데이트에서 꼭 반영하겠습니다.
