# MATE:ON — Play Console 데이터 안전 영역 답변 초안

앱은 기본적으로 **로컬 퍼스트**: 모든 데이터는 기기 안(localStorage / IndexedDB)에만 저장되고, 개발자 서버로 자동 전송되는 정보가 없습니다.

## 수집 및 공유하는 데이터

| 항목 | 수집 여부 | 비고 |
|------|-----------|------|
| 이름/닉네임 | 수집 | 기기 내 저장만. 사용자가 직접 입력한 표시명. 초대 링크 공유 시 상대 기기로 전달될 수 있음(사용자 선택) |
| 생활 데이터 (지출·집안일·일정·체크인·대화 메모 등) | 수집 | 기기 내 저장만. 사용자가 "백업보내기"로 파일을 만들 때만 기기 밖으로 나감 |
| 사진 (영수증·인증샷) | 수집 | 기기 내 IndexedDB 저장만, 외부 업로드 없음 |
| 위치 | 수집 안 함 | — |
| 연락처 | 수집 안 함 | — |
| 진단 결과/성향 점수 | 수집 | 기기 내 저장만. 초대 링크에 인코딩되어 사용자가 직접 공유 |
| 오류 기록 | 수집 | 최근 20개, **기기 내 저장만**. 서버 전송 없음 |
| 광고 식별자/분석/추적 | 수집 안 함 | 광고·분석 SDK 없음 |

## 선택적 기능 (사용자가 직접 켤 때만 동작)

- **메이트 동기화**: 사용자가 설정에서 직접 서버 주소·방 코드를 입력한 경우에만 활성화. 전송되는 데이터는 위 생활 데이터이며, 동기화 서버는 사용자 본인이 배포한 인스턴스(Cloudflare Worker 템플릿)입니다.
- **백업 파일**: 사용자가 명시적으로보낼 때 JSON 파일(선택적 AES 암호화)이 생성됩니다.
- **알림**: 로컬 알림만 사용, 푸시 서버 없음.

## 보안

- 앱 잠금(PIN 해시 + 플랫폼 생체 인증), 암호화 백업(PBKDF2+AES-GCM)
- 서비스 워커는 앱 셸만 캐시, 사용자 데이터는 캐시하지 않음

## 삭제

설정 → 데이터 관리 → "모든 데이터 삭제"로 기기 내 데이터 완전 삭제 가능. 서버에 보관되는 데이터가 없으므로 별도 삭제 요청 절차가 필요 없습니다.
