# Play 스토어 프로모션 영상 스크립트 (30초)

타겟: 동거·결혼 준비 커플, 20-30대. 톤: 따뜻하고 구체적 — 기능 나열이 아니라 "함께 사는 장면".

## 콘티

| 시간 | 화면 | 자막/나레이션 | 비고 |
|------|------|---------------|------|
| 0-3s | 짐 상자를 나르는 두 사람 (스톡 or 일러스트) | "같이 살기로 했다." | 로고 없이 시작 — 몰입 유도 |
| 3-8s | 진단 화면 — 문항 카드 넘기는 탭 | "근데 청소는 내가 다 할 것 같고, 돈 얘기는 괜히 어색하고." | 설문 실제 UI 캡처 |
| 8-13s | 16유형 캐릭터 + 궁합 리포트 | "MATE:ON은 서로의 생활을 미리 보여줘요. 청소·소비·수면 — 달라도 되는 부분과, 미리 정해야 할 부분." | 캐릭터 그리드 → 리포트 전환 |
| 13-19s | 합의서 체크 → 서명 | "말로만 한 약속 말고, 우리 규칙으로 정리해요." | 규칙 토글 + 서명 애니메이션 |
| 19-25s | 생활 도구 몽타주 (정산·쇼핑·캘린더·체크인 2x2) | "지출은 자동 정산, 장보기는 같이, 오늘 기분은 한 줄 체크인." | 실제 화면 빠른 컷 |
| 25-30s | 로고 + 태그라인 | "함께 살 준비, 서로를 아는 것부터. MATE:ON — 무료, 광고 없음." | `assets/logo-symbol.svg` + 앱 아이콘 |

## 제작 노트

- 화면 캡처: `npm run shots`(ko)·`npm run shots:en`(en)으로 고해상 스틸 확보 → ken-burns 줌으로 영상화 가능
- 배경음: 가벼운 어쿠스틱, 보컬 없는 트랙 (스토어 정책상 자동재생 음소거라 자막 필수)
- 자막은 하단 1/3, 최대 12자/줄 — 작은 화면에서도 읽히게
- CTA는 "무료·광고 없음·회원가입 없음" 중 하나만 — 가장 강한 진입 장벽 제거 메시지는 "회원가입 없음"
- YouTube 비공개 링크로 올리면 Play Console의 "프로모션 동영상" 필드에 바로 입력 가능
