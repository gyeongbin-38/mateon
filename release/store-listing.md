## 짧은 설명 (80자)

함께 살기 전, 서로의 생활방식을 미리 알아보는 동거 성향 진단

## 상세 설명 (초안)

MATE:ON은 함께 살기를 준비하는 두 사람을 위한 성향 진단·생활 합의 서비스입니다.

• 20문항 진단으로 16가지 동거 캐릭터 중 나의 유형을 확인해요
• 초대 링크·QR로 메이트와 연결하면 두 사람의 궁합 리포트가 완성돼요
• 갈등이 생기기 쉬운 부분을 미리 보고, 우리만의 생활규칙을 합의서로 만들어요
• 생활비 정산, 집안일 분담, 우리 일정, 주간 체크인까지 함께 관리해요

모든 데이터는 여러분의 기기에만 저장됩니다. 회원가입이 없고, 서버로 응답을 보내지 않습니다.

## 스크린샷 체크리스트 (5장 권장)

- [ ] 1. 홈 — 미션 카드 + 캐릭터 캐러셀
- [ ] 2. 진단 — 문항 카드 + 진행률
- [ ] 3. 궁합 리포트 — 두 유형 비교 + 갈등 예측
- [ ] 4. 생활 합의서 — 규칙 선택 + 서명
- [ ] 5. 우리 공간 — 정산·분담·체크인 도구 모음
